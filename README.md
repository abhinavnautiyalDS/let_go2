## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Project architecture

The current production routes and ritual engine are being kept stable while the codebase is prepared for incremental feature growth. See [Repository Structure](docs/architecture/REPOSITORY_STRUCTURE.md) for the target folder layout, desktop/mobile component strategy, import boundaries, migration sequence, and Cloudflare deployment safeguards.

### Development principles

- Keep route URLs and public asset paths stable during refactors.
- Separate desktop and mobile page compositions only where their UX differs; share state, domain logic, validation, APIs and the ritual engine.
- Implement new capabilities as isolated features rather than expanding route components.
- Merge structural changes only after typecheck, lint, build and Cloudflare preview checks.
